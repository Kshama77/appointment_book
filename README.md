# AppointmentBook

A beginner-friendly Java console app to schedule and manage appointments.

## Features
- Add appointments (name, date, time, purpose)
- View all appointments
- Search appointments by name
- Delete appointments by list number

## Java concepts used
- Classes and objects
- Fields, constructors, and methods
- `ArrayList`
- `Scanner` input
- `if/else` and `switch`
- `for` loops
- Basic string comparisons

## Requirements
- Java 8 or newer

## Run
1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Compile the source files:
   ```bash
   javac src/*.java
   ```
4. Run the app:
   ```bash
   java -cp src AppointmentBook
   ```

> Appointments are stored in memory only and will be cleared when the program exits.
